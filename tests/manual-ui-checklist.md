# Ручная проверка ID Vault

## Запуск

- [x] Frontend собирается `npm run build`.
- [x] Backend компилируется и выполняет идемпотентный seed.
- [x] Сервер слушает только `127.0.0.1`.
- [x] `ЗАПУСК.bat` восстанавливает отсутствующие зависимости и собирает frontend.

## Объекты и реестр

- [x] Стартовый экран показывает активные объекты и архив отдельно.
- [x] Открытие объекта сохраняет его как текущий.
- [x] Реестр фильтруется по каждой группе.
- [x] Можно добавить свою группу.
- [x] Можно импортировать поддерживаемый файл в текущую группу.
- [x] Исходный импортированный файл открывается из приложения.

## Шаблоны

- [x] Библиотека содержит реестры, журналы, акты, испытания, схемы и приказы.
- [x] Preview показывает авто- и ручные поля.
- [x] Пресет дополняет поля без выдумывания неизвестных значений.
- [x] Черновик создаётся внутри объекта и выбранной группы.
- [x] Редактор строится по полям конкретного шаблона.
- [x] Выпуск блокируется, пока обязательные поля не заполнены.
- [x] Сформированный DOCX доступен из редактора.
- [x] После редактирования ссылка на устаревший DOCX сбрасывается.

## Целостность

- [x] Проверяются реестр, РД, журналы, разрешительная, акты, качество, схемы и ППР.
- [x] Незавершённый документ имеет статус «Ожидается», а не «Отсутствует».
- [x] Из проверки можно открыть именно незавершённый документ.
- [x] Не применимо/эквивалент/исключение требуют причины.
- [x] Для эквивалента требуется подтверждение.
- [x] Решение можно отменить и вернуть проверку.

## UX

- [x] `Ctrl+K` ищет объекты и документы без учёта регистра кириллицы.
- [x] `Ctrl+N`, `Ctrl+S` и `Esc` работают по контексту.
- [x] Светлая и тёмная темы сохраняются.
- [x] Основные иконки-кнопки имеют `aria-label`.
- [x] `prefers-reduced-motion` отключает необязательную анимацию.
- [x] Проверены главный экран, реестр, шаблоны, карточка и integrity-view в браузере.
