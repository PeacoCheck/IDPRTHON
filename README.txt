ГЕНЕРАТОР АКТОВ АОСР (форма по Приказу Ростехнадзора № 344 от 16.10.2022)
===========================================================================

ЧТО ЭТО
-------
Программа берёт данные из Excel-книги «АОСР_данные.xlsx» и создаёт готовые
акты освидетельствования скрытых работ в формате Word (.docx) — по одному
файлу на каждую строку реестра. Перед генерацией данные проверяются:
несостыковки дат, ссылки на несуществующие материалы и пустые обязательные
поля будут показаны с номерами строк Excel.

УСТАНОВКА (один раз)
--------------------
1. Установите Python 3.9 или новее: https://www.python.org/downloads/
   (при установке на Windows поставьте галочку «Add Python to PATH»).
2. Откройте командную строку в этой папке и выполните:
       pip install -r requirements.txt

КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Откройте АОСР_данные.xlsx и заполните листы по порядку:
      1.Объект      — данные объекта и организаций (один раз)
      2.Участники   — состав комиссии (роль — из выпадающего списка)
      3.Материалы   — реестр входного контроля с кодами М-1, М-2…
      4.Реестр актов — одна строка = один акт
   Подробная инструкция — на первом листе книги «ИНСТРУКЦИЯ».
   Подсказки — во всплывающих комментариях к заголовкам колонок.
   Первые строки заполнены примерами: замените их своими данными.

2. Двойной клик по файлу  ЗАПУСК.bat  — откроется приложение в браузере:
      • видно объект, комиссию, материалы и все акты из реестра;
      • ошибки и предупреждения показаны наглядно, с номерами строк;
      • каждый акт можно раскрыть и просмотреть все пункты 1–7;
      • отметьте нужные акты (или ничего — тогда сгенерируются все)
        и нажмите «Сгенерировать»;
      • готовые файлы открываются прямо из окна результата.
   Приложение работает только на вашем компьютере: это локальная
   программа, данные никуда не передаются.

3. После правок в Excel сохраните файл и нажмите «Обновить» в приложении.
   Готовые акты лежат в папке «Акты».

4. Чтобы завершить работу, закройте чёрное окно программы.

КОНСОЛЬНЫЙ РЕЖИМ (для автоматизации)
------------------------------------
   ЗАПУСК_КОНСОЛЬ.bat — генерация без браузера, как раньше.

   python generate_aosr.py --akt 5              только акт № 5
   python generate_aosr.py --file Объект2.xlsx  другой файл данных
   python generate_aosr.py --out C:\ИД\Акты     другая папка результата
   python generate_aosr.py --help               справка

   python app.py --file Объект2.xlsx            веб-интерфейс с другим файлом
   python app.py --port 9000 --no-browser       свой порт, без автозапуска браузера

НАСТРОЙКА ПОД СЕБЯ
------------------
• Имя файлов актов, папка результата и число экземпляров задаются на листе
  «1.Объект» (например, шаблон имени: АОСР_{номер}_{дата}_{работы}).
• Для нескольких объектов сделайте копии книги: Объект1.xlsx, Объект2.xlsx
  и запускайте:  python app.py --file Объект1.xlsx
• Списки ролей и типов документов можно дополнять на листе «5.Справочники».

СОСТАВ ПАПКИ
------------
   ЗАПУСК.bat          — запуск приложения (браузер)
   ЗАПУСК_КОНСОЛЬ.bat  — запуск в консоли
   app.py              — локальный веб-сервер интерфейса
   index.html          — страница приложения
   generate_aosr.py    — ядро: чтение Excel, проверки, генерация .docx
   АОСР_данные.xlsx    — ваши данные
   Акты\               — готовые акты (создаётся автоматически)

ВАЖНО
-----
• Не переименовывайте листы и заголовки колонок — скрипт ищет их по именам.
• Перед генерацией закройте старые акты в Word (файл данных закрывать
  не обязательно, но несохранённые правки Excel программа не увидит).
• Сгенерированный акт — это заготовка: проверьте её перед печатью и подписью.
