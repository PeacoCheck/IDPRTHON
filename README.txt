ИСПОЛНИТЕЛЬНАЯ ДОКУМЕНТАЦИЯ
===========================

Локальное рабочее место инженера исполнительной документации.
Запускается одним файлом:

    python app.py

или двойным кликом по:

    ЗАПУСК.bat

Приложение работает только на этом компьютере. Данные хранятся в Excel.


УСТАНОВКА
---------
Один раз установите зависимости:

    python -m pip install -r requirements.txt


СТРУКТУРА
---------
app.py
    Главный запуск, локальный HTTP-сервер и маршруты API.

core/
    objects_db.py       реестр объектов data/ИД_объекты.xlsx
    paths.py            пути, папки объектов, безопасная сборка путей
    excel_templates.py  создание Excel-файла объекта
    state.py            состояние приложения для интерфейса

modules/aosr/
    generate_aosr.py    текущий генератор АОСР
    aosr_service.py     чтение состояния и генерация АОСР для выбранного объекта

web/
    index.html          интерфейс приложения

data/
    ИД_объекты.xlsx     база объектов
    objects/            папки объектов

templates/
    АОСР_данные_шаблон.xlsx, если нужен отдельный шаблон для новых объектов


КАК ЭТО РАБОТАЕТ
----------------
При запуске app.py сам создаёт data/, data/objects/ и data/ИД_объекты.xlsx.

Если рядом с app.py есть старый файл АОСР_данные.xlsx, он автоматически
подхватывается как первый объект object_001 и копируется в:

    data/objects/object_001/АОСР_данные.xlsx

Новые объекты добавляются через интерфейс:

    Объекты -> Добавить объект

Для каждого объекта создаётся своя папка:

    data/objects/object_XXX/

и свой Excel:

    data/objects/object_XXX/АОСР_данные.xlsx

Текущий объект хранится в data/ИД_объекты.xlsx. Выбор объекта в верхней панели
реально переключает Excel-файл, из которого читается раздел АОСР.


АОСР
----
Раздел:

    Акты -> АОСР

работает через текущий Excel выбранного объекта. Старый генератор сохранён:

    python generate_aosr.py --help

Корневой generate_aosr.py оставлен как совместимая прокладка.


ПАПКИ РАЗДЕЛОВ
--------------
Папки разделов создаются автоматически при первом открытии из интерфейса.
Перед открытием локальной папки или файла браузер показывает confirm-окно.


ВАЖНО
-----
Не переименовывайте листы в АОСР_данные.xlsx:

    1.Объект
    2.Участники
    3.Материалы
    4.Реестр актов

Не нужно вручную создавать папки объектов или базу ИД_объекты.xlsx.
