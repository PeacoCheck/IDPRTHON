ID VAULT — ЛОКАЛЬНОЕ ХРАНИЛИЩЕ ИД
==================================

Запуск двойным кликом:

    ЗАПУСК.bat

Приложение работает только на 127.0.0.1. База SQLite, импортированные файлы
и сформированные DOCX находятся в папке vault рядом с приложением.


ОСНОВНОЙ СЦЕНАРИЙ
-----------------

1. Создайте или откройте объект.
2. Заполните карточку объекта — это источник автоподстановки.
3. Откройте любую группу в реестре.
4. Добавьте готовый PDF/DOCX/XLSX/DWG или создайте документ из шаблона.
5. При необходимости выберите пресет работ.
6. Заполните только фактические поля, которые система не может определить.
7. Сохраните и сформируйте DOCX.
8. Откройте вкладку «Проверка», чтобы увидеть пропуски и обоснованные исключения.


СТРУКТУРА ОБЪЕКТА
-----------------

Каждый новый объект получает группы:

    Реестр
    Проектная и рабочая документация
    Разрешительная документация
    Журналы
    Акты и испытания
    Исполнительные схемы
    Материалы и паспорта
    ППР, графики и дефектные
    Фото и подтверждения
    Архив заменённых версий
    Прочее

Можно добавлять свои группы для котла, трубопровода, насоса, фильтра или
другого узла.


ШАБЛОНЫ И ОБУЧЕНИЕ
------------------

В библиотеке есть реестры, журналы, АОСР, ВИК, входной контроль,
гидроиспытания, демонтаж/монтаж, готовность и приёмка оборудования,
исполнительные схемы, приказы и дефектные ведомости.

Поля заполняются каскадом:

    карточка объекта -> выбранная группа -> пресет -> ручные поля документа

Локальный справочный корпус: 17 объектов и 1 408 файлов из архива NAS.
Ispolnitelnaya.ru используется только как справочная библиотека форм и
примеров, а не как нормативная истина.


ПРОВЕРКА ЦЕЛОСТНОСТИ
--------------------

Статусы: найдено, ожидается заполнение, отсутствует, не применимо,
заменено эквивалентом и обоснованное исключение. Ошибку нельзя скрыть
без причины; для эквивалента требуется ссылка или подтверждение.


РАЗРАБОТКА
----------

Backend:

    python app.py --no-browser

Frontend:

    cd frontend
    npm install
    npm run build

ЗАПУСК.bat сам восстанавливает Python-зависимости и пересобирает frontend.
