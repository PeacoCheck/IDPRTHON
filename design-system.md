# ID Vault — дизайн-система

## Принципы

1. Объект — корень всей навигации и всех данных.
2. Реестр открывается первым; группа и документ — следующие уровни.
3. Интерфейс лёгкий: светлый фон, одна белая поверхность, минимум рамок и цвета.
4. В одной зоне — одно основное действие.
5. Автозаполненные и ручные значения различаются текстом, а не только цветом.
6. Неизвестное значение никогда не выдумывается.
7. Исключение из проверки требует причины и остаётся проверяемым.
8. Всё работает локально: системный шрифт, локальные SVG, никаких CDN.

## Визуальный язык

- Системный `Segoe UI Variable`.
- Нейтральный фон `#f6f7f9`, белые поверхности, мягкий синий акцент.
- Радиусы 8–12 px, тонкие границы, почти незаметные тени.
- Цвет используется только для действия или статуса.
- Motion короткий: появление страницы, sheet и hover карточки; при
  `prefers-reduced-motion` необязательные переходы отключаются.

Токены находятся в `frontend/src/styles/tokens.css`, продуктовые компоненты —
в `frontend/src/styles/product.css`.

## Информационная архитектура

```text
Объекты
└─ Объект
   ├─ Реестр
   │  ├─ Группа
   │  └─ Документ
   ├─ Проверка структуры
   └─ Карточка автозаполнения

Шаблоны
└─ Шаблон → пресет → авто/ручные поля → черновик

База знаний
├─ локальный NAS-корпус
└─ справочная публичная библиотека
```

## Ключевые компоненты

- `ObjectCard`: документы, комплектность, замечания.
- `GroupNav`: полный эталон объекта и пользовательские группы.
- `RegistryTable`: прямой переход к любому акту или файлу.
- `TemplatePicker`: формы, источник примера и число автополей.
- `ResolutionPreview`: что подставится и что надо спросить.
- `DocumentEditor`: динамические поля конкретного шаблона.
- `IntegrityRow`: найдено, ожидается, отсутствует или решено с причиной.
- `CommandPalette`: поиск объектов и документов по `Ctrl+K`.

Иконки-кнопки всегда имеют доступное имя. Focus-visible, пустые состояния,
ошибки и уведомления обязательны.
