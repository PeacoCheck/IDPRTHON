# ID Vault — дизайн-система

## Принципы

1. Объект — корень навигации и контекст для всех документов.
2. Реестр открывается первым; группа и документ — следующие уровни.
3. Экран строится как спокойная рабочая Bento Grid: разный масштаб карточек, высокая информационная плотность и одно главное действие в каждой зоне.
4. Наличие файла, рабочий статус и результат проверки комплектности не смешиваются.
5. Неизвестное значение не выдумывается; исключение требует проверяемой причины.
6. Все зависимости и шрифты собираются локально, без CDN.

## Визуальный язык

- Основной текст: `IBM Plex Sans`.
- Заголовки: `PT Sans Narrow`, вес 700.
- Коды, даты, счётчики и технические подписи: `IBM Plex Mono`.
- Светлая тема: тёплый бумажный фон `#f6f5f1`, белые поверхности и графитовый текст.
- Основной акцент для кнопок: `#d1490a`; яркий оранжевый используется только в декоративных элементах и диаграммах.
- Тёмная тема: глубокие сине-графитовые поверхности с сохранением контраста текста и статусов.
- Радиусы небольшие, границы явные, тени короткие; интерфейс должен ощущаться техническим архивом, а не маркетинговым лендингом.
- Motion длится до 400 мс и отключается для `prefers-reduced-motion`.

Токены находятся в `frontend/src/styles/tokens.css` и `frontend/src/styles/theme-dark.css`. Общие компоненты лежат в `frontend/src/styles/components.css`, стили экранов — в `frontend/src/styles/views/`.

## Ассеты и данные

- Все интерфейсные иконки берутся из Lucide; рукописные SVG-пути не используются.
- Диаграммы комплектности строятся Chart.js и получают цвета из CSS-токенов.
- Canvas является декоративным: те же числа и действия всегда доступны обычным HTML-текстом.
- DOCX в тёмной теме остаётся белым листом на тёмной рабочей поверхности.

## Информационная архитектура

```text
Объекты
└─ Объект
   ├─ Реестр
   │  ├─ Группа
   │  └─ Документ
   ├─ Проверка комплектности
   └─ Карточка объекта

Шаблоны
└─ Оригинал файла → копия в выбранный объект

Отчёт о комплектности (`#/reports/completeness`)
└─ Сводка → диаграмма → переход к объекту
```

## Ключевые компоненты

- `ObjectCard` — объект, количество файлов, рабочие итоги и комплектность.
- `GroupNav` — стандартные и пользовательские группы.
- `ArchiveRegistry` — карточки документов с прямым переходом, независимыми признаками файла и статуса.
- `PreviewDrawer` — быстрый локальный предпросмотр, статус и основные действия с файлом.
- `FileInspector` — полный экран документа с историей версий.
- `TemplateLibrary` — оригиналы шаблонов, наличие файла и копирование в объект.
- `IntegrityRow` — найдено, ожидается, отсутствует, эквивалент или обоснованное исключение.
- `CompletenessCharts` — кольцо объекта, разбивка по группам и сводный отчёт.
- `CommandPalette` — поиск объектов и документов по `Ctrl+K`.

Все интерактивные элементы имеют доступное имя, видимый `focus-visible` и управление с клавиатуры. Цвет не используется как единственный носитель смысла.
