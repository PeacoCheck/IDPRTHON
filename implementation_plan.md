# Интеграция AutoCAD вкладки в основной проект

## Что делаем

Вместо кнопки «Поиск» (которая открывала поиск командой Ctrl+K) в левом рейле добавляем вкладку **AutoCAD**. 
Кнопка поиска остаётся в топбаре (там она уже есть). Скиллы грузятся из AutoCAD микросервиса через `/autocad-api/`.

## Изменяемые файлы

### 1. `router.js` — добавить маршрут `autocad`
### 2. `components/icons.js` — добавить иконку AutoCAD (треугольник/чертёж)
### 3. `components/shell.js` — заменить кнопку поиска на вкладку AutoCAD  
### 4. `app.js` — добавить импорт и routeView для `autocad`
### 5. `views/autocad.js` — [NEW] весь вид с сеткой скиллов, версиями, поиском, историей
### 6. `styles/views/autocad.css` — [NEW] стили вида

## Архитектура API

Основной бэкенд слушает на одном порту. AutoCAD-сервис на другом.
Решение: Vite proxy или делаем прямые fetch на `http://127.0.0.1:8765/api/...` (порт из ЗАПУСК.bat).
Удобнее — хранить порт в localStorage или env. Начнём с константы `8765` — можно потом изменить.
